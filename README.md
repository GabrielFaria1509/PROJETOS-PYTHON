# 🐍 Projetos em Python

Este repositório reúne os meus códigos de estudo, exercícios práticos e scripts de automação desenvolvidos ao longo da minha trajetória com a linguagem **Python**. 

O espaço funciona como um laboratório pessoal para testar algoritmos, manipular dados com notebooks interativos e construir pequenas ferramentas utilitárias que resolvem problemas do dia a dia ou auxiliam em atividades acadêmicas.

---

## 🛠️ Tecnologias e Conceitos Explorados

* **Python 3:** Uso de sintaxe moderna, estruturas de dados nativas (listas, dicionários, tuplas) e controle de fluxo.
* **Jupyter Notebooks (`.ipynb`):** Utilizados para o desenvolvimento guiado de lógica, visualização rápida de saídas e prototipação de scripts.
* **Automação e Integração de Hardware:** Scripts para manipulação de periféricos em tempo real, como o controle e captura de streams de vídeo através de câmeras (`ControlWebcam.py`).

---
